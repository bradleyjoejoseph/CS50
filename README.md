## Final Project Spotlight: Infinity Network

- **Demo Video**: [YouTube](https://www.youtube.com/watch?v=EwcqYN_srsc)
- **Directory**: [`CS50x/2021/project`](CS50x/2021/project)
- **Stack**: Python, Flask, SQLite, HTML5, CSS3, JavaScript

*Infinity Network* is a multi-application web portal featuring games, utilities, and a community hub:
- **Infinite Spinner**: Luck-based slot/spinning game with tiers of rarity and bet scaling.
- **Blackjack**: Interactive browser implementation of the card game against the dealer.
- **Arcade Mathematicians**: Fast-paced mental math times table game.
- **Aim Trainer**: Mouse reflex accuracy training tool with configurable targets.
- **CPS Master**: Clicks-per-second measuring test with a public leaderboard.
- **Chat & Social**: Real-time forum/chat messaging system with SQLite persistence.
- **Administration**: User management, moderation tools, balance adjustments, and audit log.
